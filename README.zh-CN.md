# 抗量子加密货币资料库

[English](README.md) · 整理维护：[Balance Zhao / @balance0014](https://x.com/balance0014)

这里公开两张抗量子图背后的数据：一张部署时间线，一张算法分布与签名尺寸图。可以查项目、看来源、下载表格，也可以提交纠错。

**本版数据对应 2026 年 10 月 23 日的已发布图，资料库于 10 月 28 日公开。** 发布当天的补充检查单独记录，不把历史图改称实时数据。

- [项目对照表与逐项来源](docs/projects.md)：17 个项目的部署节点、共识、算法、保护范围和升级条件。
- [公钥和签名尺寸](docs/signature-sizes.md)：12 组参考值，其中 8 组展示在原图中；不是完整交易大小，也不是安全排名。
- [下载 CSV](data/projects.csv) 或 [JSON](data/projects.json)：方便自己分析和制作图表。
- [报告错误或补充项目](CONTRIBUTING.md)：请附原始来源、具体网络和版本，我们核实后更新。

Mochimo 按迁移后的 PoS 记录；QANplatform 是测试网；Starknet 的 L1 投票支持研究，尚未批准迁移；Raqcoin 的 2018 年是前身创世，不是 UOV 启用年份。Quantus 和 qtcchain 同用 QTC 代号，但不是同一条链。

资料库帮助读者判断“用了什么、保护哪里、有什么条件”，不证明整条链已经抗量子，也不替项目作投资或安全背书。算法参数和工程边界主要查原始规范，项目部署查文档、代码和公开链资料；它们证明的范围不同。
